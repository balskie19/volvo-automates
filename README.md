# Volvo Automates

The site and the CV for Volvo Ebal: GoHighLevel, n8n, and applications built with Claude Code.

- `index.html` is the deck. Arrow keys, scroll, or the Next button.
- `cv/index.html` is the CV. It prints to A4.

## Deploy

`node tools/deploy.mjs` publishes to Cloudflare Pages at https://volvo-automates.pages.dev
The GitHub Pages copy at https://balskie19.github.io/volvo-automates/ is a mirror and updates on push.

Plain HTML. No build step, no dependencies.
