How I work

  • Every build carries its failure. I publish what broke and what it cost, not only what shipped. A portfolio that lists wins alone is a brochure.
  • Silent failure is the real enemy. Anything I build reports into a channel you already read, and says so when it stops.
  • Your tools, not mine. If it has an API or a webhook it can be wired in. If it does not, I build the missing piece.
  • I will tell you not to automate something. If a process does not cost real hours or real leads, automating it is a hobby.
